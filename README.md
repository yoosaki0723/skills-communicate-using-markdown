# Communicate using Markdown（日本語版）

_テキストを整えるための軽量な言語 Markdown で、考えを整理し、共同作業する。_

> このリポジトリは GitHub Skills「[Communicate using Markdown](https://github.com/skills/communicate-using-markdown)」（MIT License）の日本語版です。
> 演習の進め方と自動チェックの仕組みは原本と同じで、Issue に投稿される手順の本文だけを日本語にしています。

## ようこそ

GitHub はコードだけの場ではありません。ソフトウェア開発で共同作業するためのプラットフォームであり、Markdown は issue や pull request でのやり取りを分かりやすく整理するための、最も大切な手段の 1 つです。この演習では、見出しをより効果的に作って使う方法、箇条書きで考えを整理する方法、チェックリストでどこまで終わったかを示す方法を扱います。絵文字・画像・リンクを使って、成果物に厚みを持たせることもできます。

- **対象**: 開発を始めたばかりの人、GitHub を初めて使う人、学生
- **学ぶこと**: コメントやテキストファイルに、Markdown でリスト・画像・リンクを入れる方法
- **作るもの**: プレーンテキストのファイルを更新して Markdown の書式を付けます。作ったファイルは、自分の GitHub Pages サイトを始めるときにも使えます
- **前提**: この演習では pull request を扱い、ファイルの編集も行います。慣れていない場合は、先に [Introduction to GitHub](https://github.com/skills/introduction-to-github) の演習を受けることを推奨します
- **所要時間**: 1 時間以内

この演習で行うこと:

1. 見出しを追加する
2. 画像を追加する
3. コード例を追加する
4. タスクリストを作る
5. pull request をマージする

### 演習の始め方

演習を自分のアカウントにコピーし、Octocat（Mona）が最初のレッスンを準備するまで **20 秒ほど**待ってから、**ページを再読み込み**してください。

3. ページが自動で更新されないときは、[Actions](../../actions) タブを確認する。
